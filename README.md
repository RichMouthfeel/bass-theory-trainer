# Root Position

A self-contained music theory trainer built around the fretboard — scales, modes,
keys, chord-scale relationships for soloing, and a set of drills. Built for bass,
with a Bass/Guitar toggle for 6-string standard tuning.

## Sections

- **Fretboard** — pick a root and a scale or mode (all seven modes, both
  pentatonics, blues, harmonic/melodic minor) and see it mapped across the neck,
  degree by degree, color-coded by chord tone.
- **Circle of Fifths** — click through all twelve major keys to see key
  signature, altered notes, and relative minor.
- **Soloing** — chord-scale relationships for the chord types you'll actually
  see on a chart (maj7, 7, m7, m7♭5, °7, m/maj7), each with a bass-specific tip,
  plus an explainer on why the reference is written in 7th chords rather than
  triads.
- **Drills** — three no-pressure quizzes: name the note at a fret, name the
  interval between two frets on a string, and build a full scale by tapping
  every matching fret.

## Running it

It's a single static HTML file with no build step and no dependencies beyond a
Google Fonts stylesheet. Open `index.html` directly in a browser, or serve the
repo with GitHub Pages (Settings → Pages → deploy from `main`, root).
